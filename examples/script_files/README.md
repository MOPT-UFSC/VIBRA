# script_files

Example Python scripts that set up and run analyses through the vibra API.

- `coupled_fluid_pipe_fsi.py` — coupled fluid-pipe analysis (FSI).
- `expansion_chamber.py` — acoustic expansion chamber.
- `structural_discharge_piping.py` — structural analysis of discharge piping.

These scripts can be previewed with:

```
vibra --preview path/to/file.py
```
