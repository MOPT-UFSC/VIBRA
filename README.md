# Vibra

## Poetry commands
```
poetry install
```

```
poetry run python vibra
```

```
poetry run pytest
```

```
poetry run black
```
## Generate Installer
```
poetry run pyinstaller vibra.spec --noconfirm
ISCC.exe /O"dist" /F"vibra-setup" "vibra.iss"
```
